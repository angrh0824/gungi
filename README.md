# 軍儀（GUNGI）対局盤

HUNTER×HUNTER キメラアント編に登場するボードゲーム「軍儀」を、ブラウザで遊べるようにしたものです。

**遊ぶ: https://angrh0824.github.io/gungi/**

- **CPU と対局**: やさしい〜最強の4段階。自己対局で学習した評価関数と αβ 探索で指します
- **オンライン対戦**: 右上の「オンライン」から。いまオンラインの人数・対戦待ちの人数が見えます。対戦待ちの人に申し込むか、自分が待って招待リンクを友達に送ります
- **AI補助**: 形勢（評価値）と最善手の矢印。オンライン対戦では、相手が AI補助 やヒントを使っているかが表示されます
- **ふたりで対局**（1台を交代で）、**CPU どうしの観戦**、棋譜の見返し（感想戦）・コピー・読み込み
- ルールは入門・初級・中級・上級、固定配置・自由配置に対応

オンライン対戦は、公開の MQTT 中継サーバー（broker.emqx.io）を通して指し手をやりとりします。名前と指し手はほかの人からも見える可能性があります。

このリポジトリは公開用の配布物だけを置いています（学習のプログラムやデータは含みません）。
